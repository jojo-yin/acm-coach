## Path C — Code Review: 0/1 背包

---

### 1. 复杂度分析

| 指标 | 值 |
|------|----|
| 时间复杂度 | O(n × W) = 100 × 10^5 = **10^7 次操作** |
| 空间复杂度 | O(n × W) = (101 × 100001) ≈ **10^7 个 int** ≈ 40 MB |

10^7 次操作在 1s 限制下完全可行，复杂度符合约束要求。

---

### 2. 正确性

DP 转移方程是正确的标准 0/1 背包写法：
```
dp[i][j] = max(dp[i-1][j], dp[i-1][j - w[i-1]] + v[i-1])
```
"不选"和"选"的决策分支完整，没有遗漏。

---

### 3. 边界测试

| 边界情况 | 预期行为 | 是否通过 |
|----------|----------|----------|
| n=1, W=0 | dp[1][0] = 0，输出 0 | 通过 |
| 所有物品重量 > W | 始终走不选分支，输出 0 | 通过 |
| 物品重量 w=0 | `j >= 0` 恒真，正确比较选与不选 | 通过 |
| n=100, W=10^5, 全选 | 累加所有 v[i] | **溢出** |

---

### 4. 核心问题：int 溢出 - 影响正确性

**严重程度：CRITICAL**

约束给出 `v[i] ≤ 10^9`，n ≤ 100，因此最大总价值可达：

```
100 × 10^9 = 10^11
```

但 `dp` 数组声明为 `vector<vector<int>>`。`int` 在 C++ 中通常为 32 位，最大值约 **2.14 × 10^9**。

10^11 远超 int 范围，溢出后的值会 wrap around 为负数或错误值，导致 `max()` 比较选出错误结果。

**修复：将 dp 的类型改为 `long long`。**

```cpp
vector<vector<long long>> dp(n + 1, vector<long long>(W + 1, 0));
```

注意关联变量也需要同步：`v` 也应该改为 `vector<long long>` 或至少保证 `v[i-1]` 与 `long long` 相加时不截断。

---

### 5. 优化建议（非必须）

| 问题 | 建议 | 优先级 |
|------|------|--------|
| 空间 O(n×W) = 40MB（修复为 long long 后约 80MB） | 可优化为滚动数组 / 1D 逆序 DP，降至 O(W) ≈ 0.8MB | 建议（非必须，256MB 限制下够用） |

1D 优化写法参考：
```cpp
vector<long long> dp(W + 1, 0);
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

这样既修复了溢出，又将空间从 ~80MB 降到 ~0.8MB。

---

### 6. 总结与行动项

**总体评价：逻辑正确，但存在一个会导致 WA 的 int 溢出缺陷。**

优先级排序：

| # | 问题 | 严重程度 | 操作 |
|---|------|----------|------|
| 1 | `dp` 和 `v` 使用 `int`，总价值可达 10^11 溢出 | **CRITICAL** | 改为 `long long` |
| 2 | 空间 O(n×W) 偏高，修复 long long 后 ~80MB | 建议 | 可优化为 1D 数组 |

将 `dp` 和 `v` 改为 `long long` 后，此代码即可在给定约束下 AC。
