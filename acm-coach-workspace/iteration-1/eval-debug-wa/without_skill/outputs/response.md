# Code Review: WA 分析

## 题目回顾

给定数组 `a[1..n]`，每次操作可以选择相邻两个数，把**较小的**删掉。问最后剩下的那个数最大可能是多少。

## 问题分析

每次操作的核心规则是：**较大者存活，较小者被删除**。这意味着：

1. 数组中的最大值 `M` 没有任何元素比它大，所以 `M` **永远不会被删除**。
2. `M` 可以不断"吃掉"相邻的较小元素，逐步向两端扩展。
3. 对于任何小于 `M` 的元素 `x`，最终一定会与某个更大的元素相邻并被删除。

因此，**答案就是数组的最大值 `max(a)`**。

举例验证：

- `[3, 1, 5]`：5 吃 1，得 `[3, 5]`，5 再吃 3，得 `[5]`。答案是 5 = max。
- `[2, 3, 1]`：3 吃 2，得 `[3, 1]`，3 再吃 1，得 `[3]`。答案是 3 = max。
- `[5, 3, 5]`：两边都是 5（最大值），中间 3 被任意一个 5 吃掉，剩下两个 5 中任意一个存活。答案是 5 = max。

## 你的代码的问题

### 1. 算法完全不对（核心问题）

你的代码计算的是 **所有元素的乘积 mod 1000000007**：

```cpp
int ans = 1;
for (int i = 0; i < n; i++) {
    ans = ans * a[i] % 1000000007;
}
```

这和题目要求的「每次删除相邻两数中较小的那个，求最终能剩下的最大值」完全是两个不同的问题。你求的是乘积，而题目要的是最大值。

**正确的做法**：

```cpp
void solve() {
    int n; cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int ans = *max_element(a.begin(), a.end());
    cout << ans << '\n';
}
```

### 2. 整数溢出问题

即使题目真的是求乘积，你的代码也有溢出问题：

- `a[i]` 最大是 `10^9`
- `ans * a[i]` 在做乘法时两个 `int` 相乘，结果可能高达 `~10^18`，远超 32-bit `int` 的范围（约 `2.1×10^9`），在取模之前就已经溢出了
- 应该使用 `long long`：`long long ans = 1; vector<long long> a(n);` 或者做类型转换 `1LL * ans * a[i] % MOD`

### 3. 不必要的取模

题目问的是最大值（`a[i] ≤ 10^9`），输出就是一个整数，根本不需要取模。

## 总结

| 问题 | 严重程度 |
|------|---------|
| 算法错误：求了乘积而非最大值 | **致命** |
| `int` 乘法溢出 | 严重（但如果改对算法就不存在了） |
| 不必要的取模 | 不适用 |

**只需要改成输出 `max(a)` 即可通过。**
