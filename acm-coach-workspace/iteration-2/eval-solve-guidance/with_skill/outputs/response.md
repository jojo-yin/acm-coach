## Stage 1: 约束分析 (READ)

先把约束翻译成复杂度预算：

| 约束 | 含义 |
|---|---|
| n ≤ 2×10^5 | 算法最多 O(n log n)，O(n^2) 必 TLE |
| l_i, r_i ≤ 10^9 | 坐标范围很大，**不能**用值域数组（如 `bool vis[10^9]`），必须用基于排序的方法 |
| 无多测限制 | 看起来是单组数据，不用考虑 ∑n |

结论：你需要一个 **O(n log n)** 的算法，排序是可以的，但不要有嵌套循环。

## Stage 2: 算法设计 (THINK)

### 第一步：问题归类

看关键信号——题目问的是「选**最少**的点」来满足某条件。查一下问题分类表：

> "minimum/maximum" + choices → **Greedy, DP, or Binary Search on answer**

你直觉觉得 DP 行吗？区间有 n 个，如果你定义 `dp[i] = 前 i 个区间最少需要多少点`，转移的时候你需要知道上一个点放在哪，状态空间直接炸掉。所以 DP 不现实。

那剩下**贪心**和**二分答案**。这种「最少点覆盖区间」的问题实际上是区间贪心里的一个经典模型。

### 第二步：给你一个引导性问题

先别急着看答案，想一想这个问题：

> 如果所有区间都**共享一个公共交点**（即存在某个 x 在所有区间里），那最少需要多少个点？

显然，1 个点就够了，放在那个公共区域里的任何位置都行。

那问题就变成了：**你选一个点，它能「消灭」哪些区间？** 消灭完之后，再从剩下的区间里继续选点。这就很贪心了。

### 第三步：怎么选点最划算？

关键问题：**一个点放在哪里，能尽可能多地覆盖区间？**

考虑两个区间 `[1, 5]` 和 `[2, 3]`。你把点放在 3，两个都覆盖了。放在 5，同样两个都覆盖。但放在 1 呢？`[2, 3]` 不包含 1，所以不行。

**核心观察**：要覆盖一个区间，点必须落在 `[l_i, r_i]` 里面。如果你把点放在区间的最右边（即 `r_i`），它不会让你丢失任何可能被这个区间覆盖的机会——因为任何 ≤ r_i 的点都在合法范围内，而把点放在 r_i 给了这个点最大的「向右延伸能力」，能尽量覆盖到右端点更远的其他区间。

### 第四步：贪心策略（提示到这里，你想一想）

基于上面的观察，策略是这样的：

1. **按右端点从小到大排序**所有区间。
2. 选排序后第一个区间（右端点最小的区间），**在它的右端点放一个点**。
3. 跳过所有已经被这个点覆盖的区间（即 `l_i ≤ 当前点 ≤ r_i`）。
4. 找到第一个没被覆盖的区间，重复步骤 2。

### 在你继续之前，手动模拟一下

假设有这 4 个区间：

```
[1, 3]
[2, 5]
[3, 6]
[4, 7]
```

按右端点排序后：`[1,3] [2,5] [3,6] [4,7]`

- 第一个区间 `[1,3]`，放点在 3 → 覆盖了 `[1,3]`、`[2,5]`、`[3,6]`。
- 下一个没被覆盖的是 `[4,7]`，放点在 7 → 覆盖 `[4,7]`。
- 总共 2 个点。

你能验证一下只用 1 个点行不行吗？如果 1 个点可以，那它必须在所有 4 个区间里——但 4 个区间的交集是空集，所以 2 个点确实是最优的。

### 第五步：为什么这样贪心是正确的？（想挑战的话）

用**交换论证 (exchange argument)**：假设最优解没有在右端点最小的那个区间的右端点放点，那你总可以把它第一个点的位置**右移**到那个右端点，不会让覆盖的区间变少（因为所有被原位置覆盖的区间，它们的右端点都 ≥ 原位置，而左端点 ≤ 原位置 ≤ 新区间右端点... 等等，这个证明需要仔细写）。

**留给你的思考**：如果你按**左端点**排序会怎样？试一试上面那个例子，按左端点排 → `[1,3] [2,5] [3,6] [4,7]`（恰好一样），所以换个例子：`[1,10] [2,3] [4,5]`。按左端点排序你会先处理 `[1,10]`，把点放在哪？如果放在 10，那 `[2,3]` 和 `[4,5]` 都被覆盖了，1 个点就够——这恰好也是最优。但如果是 `[1,2] [3,10] [4,5] [6,7]` 呢？试试看按左端点和按右端点各会得到什么答案。这会让你深刻理解**为什么必须是按右端点排序**。

### 总结

| 项目 | 内容 |
|---|---|
| 算法 | 贪心 (Greedy) |
| 复杂度 | O(n log n) —— 排序主导 |
| 核心排序键 | 右端点 r_i |
| 贪心选择 | 每次在未覆盖区间中右端点最小的那个区间的 r_i 处放点 |
| 正确性 | 交换论证 (exchange argument) |
